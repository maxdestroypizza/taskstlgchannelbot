# Telegram Task Bot — канальная версия

Бот публикует задания в Telegram-канале. Первый нажавший кнопку берёт задание.

---

## Настройка (делать один раз)

### 1. Создай бота
- Напиши @BotFather → /newbot
- Получи BOT_TOKEN

### 2. Узнай свой Telegram ID
- Напиши @userinfobot
- Запомни свой числовой ID (например 123456789)

### 3. Добавь бота в канал как администратора
- Открой канал → Администраторы → Добавить
- Найди своего бота, дай права на публикацию постов

### 4. Узнай ID канала
- Публичный канал: просто @username_канала
- Приватный канал: перешли любой пост из канала боту @userinfobot → он покажет ID вида -1001234567890

---

## Запуск на Render.com (бесплатно)

1. Загрузи файлы на GitHub (новый репозиторий)
2. Render.com → New → Web Service → подключи репозиторий
3. Настройки:
   - Runtime: Python
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `python bot.py`
4. Environment Variables (раздел в настройках):
   - `BOT_TOKEN` = токен от @BotFather
   - `CHANNEL_ID` = @username_канала или -1001234567890
   - `ADMIN_IDS` = твой Telegram ID (например 123456789)
   - Если несколько админов: 123456789,987654321
5. Deploy!

---

## Локальный запуск

```bash
pip install -r requirements.txt
BOT_TOKEN=xxx CHANNEL_ID=@mychannel ADMIN_IDS=123456789 python bot.py
```

---

## Использование

Админ пишет боту в личку:
```
/task Написать статью про Python до пятницы
```

Бот публикует в канале:
```
📋 Задание:

Написать статью про Python до пятницы
[✅ Взять задание]
```

Первый кто нажал кнопку — пост обновляется:
```
📋 Задание:

Написать статью про Python до пятницы

🏆 Задание взял: @username
```

Остальные видят всплывающее сообщение: "Опоздал! Задание уже взял @username 😔"
